# 产品交互改动记录

## 2026-04-28 — 知识库全页管理

**用户痛点：** 上传 PDF 后生成的知识文档无处查看和编辑，初版管理入口在左侧面板底部，点击后只有一小块区域，"什么也看不到"。

**解决方案：** 点击"管理"按钮打开全屏知识库页面，而非内嵌小面板。

**核心交互流程：**

1. **浏览知识** — 进入全屏页面，左侧按分组/文件导航，右侧展示知识片段卡片
2. **搜索** — 顶部搜索栏实时过滤（debounce），支持模糊匹配内容、文件名、技术点
3. **编辑知识** — 点击卡片上的编辑按钮，右侧滑出编辑抽屉，可修改内容和分组
4. **删除知识** — 卡片 hover 出现删除按钮，点击确认删除
5. **手动添加** — 顶部"+ 添加"按钮，打开空白编辑抽屉
6. **分组管理** — 左侧可创建自定义分组（如"前端面试"、"后端面试"），文件可归组
7. **多格式上传** — 支持 PDF 和 Markdown 文件，Markdown 按标题自动分段
8. **返回** — 左上角返回按钮或 Escape 键关闭全屏页面
9. **视图切换** — 列表视图 / 网格视图，适应不同浏览偏好

## 2026-04-28 — RAG 过程可视化

**用户需求：** "我能不能看到 AI 引用这个文档的过程？"

**解决方案：** AI 回答下方增加可折叠的调试面板，展示完整 RAG 管道：

1. AI 从转写文本中提取了什么问题
2. 用什么关键词搜索知识库
3. 搜到了哪些片段、相似度分数多少
4. 是否补充了 Web 搜索
5. 最终排序后选了哪些内容
6. 送给 LLM 的完整上下文
7. 各步骤耗时

**目标用户：** 希望理解和调优 AI 回答质量的高级用户

## 2026-04-28 — 语音识别引擎切换

**用户场景：** 
- 有网络时用云端识别（准确率更高、支持更多语言特性）
- 无网络 / 想节省费用时用本地识别

**交互流程：**
1. 打开设置 → 选择"本地识别"
2. 自动检测模型是否已下载
3. 未下载 → 显示"下载模型"按钮 + 大小提示
4. 点击下载 → 显示进度条（下载 → 解压）
5. 完成后显示"已就绪"，即可开始本地录音识别
6. 设置持久化到 localStorage，下次启动自动恢复

**切换无感：** 录音的操作方式完全一致，用户只需在设置中切换引擎，无需改变使用习惯

## 2026-04-27 — 系统音频捕获

**用户场景：** 视频面试时需要同时识别自己说的话和面试官说的话。

**交互：** 
1. 设置面板开启"捕获系统音频"开关
2. 首次使用弹出 macOS 屏幕录制权限请求
3. 授权后，录音自动混合麦克风 + 系统音频
4. 无需安装第三方虚拟声卡（如 BlackHole）

## 2026-04-27 — AI 面试助手双模式

**面试者模式（被面试）：**
1. 录音 → 实时转写出现在左侧
2. VAD 静音检测自动分段，每段独立处理
3. AI 自动识别面试问题（绿色高亮显示）
4. 自动触发 RAG：搜索知识库 + Web → 生成参考答案
5. 答案以流式 Markdown 渲染，下方显示引用来源和相似度分数
6. 也可手动点击"获取 AI 建议"触发

**面试官模式（面试别人）：**
1. 输入 JD（职位描述）
2. 点击"推荐问题"→ AI 根据 JD + 知识库生成面试问题
3. 点击"评估回答"→ AI 评估候选人回答质量

## 2026-04-27 — PDF 简历分析流程

**交互流程：**
1. 点击"上传文档"选择 PDF
2. 弹出 4 步进度面板：
   - Step 1: 解析 PDF（显示页数）
   - Step 2: AI 分析技术栈（显示发现的技术点数量）
   - Step 3: 逐个生成知识文档（流式显示生成过程，如"生成中: React 虚拟 DOM 原理"）
   - Step 4: 向量化存储
3. 完成后知识库列表更新，AI 回答时自动引用
