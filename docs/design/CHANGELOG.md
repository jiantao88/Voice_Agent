# 设计改动记录

## 2026-05-01 — 知识库二级分组 UI

**背景：** 用户反馈知识库无法区分不同岗位，侧边栏原本只有扁平的自定义分组列表。

### Header 改动
- 顶栏 header-center 新增岗位选择下拉框（`#positionSelect`）
- 知识库管理页 header-right 新增"自动分类"按钮
- header left-padding 80px 避开 macOS 红绿灯按钮

### 侧边栏二级树
- 岗位节点（▶/▼ 展开折叠）+ 域名子节点（缩进 28px）
- 岗位显示域名数量 badge
- 右键岗位或域名可删除（confirm 确认）
- 新建分组：inline form（select 岗位 + input 域名 + 确认/取消按钮），替代原来的 `window.prompt()`（Electron 中不可用）

### 知识片段卡片
- 新增岗位标签（`.kb-chunk-tag.position`）和领域标签
- 编辑抽屉中分组选择改为 `<optgroup>` 按岗位层级展示

### 文件分配
- 点击文件列表项显示"分配到"面板，下拉选择岗位/领域后一键分配

## 2026-04-28 — 知识库管理页面全屏重设计

**背景：** 初版知识库管理放在左侧面板底部的一个小区域内，点击"管理"后只展示一小块列表，用户反馈"点击管理什么也看不到，交互太不友好了，应该打开一个新的页面"。

**设计方案：**

### 全屏覆盖层（`#kbFullpage`）
- fixed 定位全屏覆盖，z-index 200，slide-in 动画
- 三栏布局：顶部操作栏 + 左侧导航栏 + 右侧内容区

### 顶部操作栏
- 左：返回按钮 + 标题 + 知识片段数量
- 右：上传文档按钮 + 手动添加按钮

### 左侧导航栏（220px）
- 分组列表：支持"全部"和自定义分组，点击筛选
- 文件列表：按文件名分类，显示 chunk 数，点击筛选
- 新建分组按钮（虚线边框样式）

### 右侧内容区
- 搜索栏 + 列表/网格视图切换
- 知识片段卡片：显示来源文件名、分类标签（PDF/Markdown/手动）、内容预览（max-height 80px + 底部渐变遮罩）、时间戳、hover 显示编辑/删除按钮
- 网格模式：`grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))`

### 编辑抽屉（480px 右侧滑出）
- 半透明遮罩层（z-index 300）
- 表单：分组选择 + 文件名 + 内容文本域
- 底部取消/保存按钮

### 色彩体系
- 背景层级：`#0f0f0f` → `#151515` → `#1a1a1a` → `#1e1e1e`
- 分类标签色：PDF 紫（`#2a1a3a/#c8a8ff`）、Markdown 青（`#1a2a2a/#88c8c8`）、手动 黄（`#2a2a1a/#c8c888`）、分组 蓝（`#1a2a3a/#8ac8ff`）
- 交互：hover 边框高亮，操作按钮渐显

## 2026-04-28 — RAG 调试面板

**位置：** AI 引用列表下方，可折叠面板

**展示内容：**
1. 提取的问题（extractedQuestion）
2. 搜索查询（searchQuery）

5. 排序后结果

7. 各阶段耗时

**样式：** 暗色调试面板风格，分数条用 `#4a9eff` 蓝色，耗时用 `#4aff9e` 绿色

## 2026-04-28 — 设置面板扩展：ASR 引擎选择

**新增 UI 元素：**
- 语音识别引擎下拉框：云端识别（豆包）/ 本地识别（Paraformer）
- 模型状态指示：图标 + 文本（检测中⏳ / 已就绪✅ / 未下载⚠️ / 失败❌）
- 下载模型按钮（仅未下载时显示）
- 进度条：6px 高度、圆角、绿色填充 + 百分比文字

**交互逻辑：**
- 切换到"本地识别"时自动检测模型状态
- 未下载 → 显示下载按钮和大小提示（约 230MB）
- 下载中 → 隐藏按钮、显示进度条、图标切换（⬇️→📦）
- 下载完成 → 显示✅已就绪
